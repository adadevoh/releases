# Shel v1.0.1 Release Notes

## 🆕 New Features

### Event Activity Tracking
- Events now track the timestamp of their most recent activity via a new `lastModified` field
- On event creation, `lastModified` equals `createdAt`
- When a user logs an entry, `lastModified` updates to that entry's timestamp (if it's later)
- Deleting an entry does not change `lastModified`

### Improved Event Feed Sorting
- The events feed now displays events sorted by their most recent activity, not creation time
- Freshly active events bubble to the top automatically
- When you log an entry on an older event, that event moves to the top of your feed
- Backdated entries (logging with a past timestamp) do not reorder the feed

### Better Mobile Navigation
- Account actions (Delete account, Logout) now collapse into a compact dropdown menu on mobile
- Desktop users continue to see inline buttons for quick access

## 🐛 Bug Fixes & Improvements

- Improved mobile layout by using `whitespace-nowrap` on action buttons
- Enhanced entry deletion logic to correctly track event state
- Better timestamp handling for backdated entries

## 📝 API Changes

### Event Response
The `EventResponse` contract now includes the `lastModified` field:
```json
{
  "id": "...",
  "name": "...",
  "topic": {...},
  "createdAt": "2026-01-01T00:00:00Z",
  "lastModified": "2026-01-02T12:30:00Z",
  "entryCount": 3
}```
