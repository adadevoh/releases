# SHeL v1.0.0 Beta

SHeL is a shared event log for coordinating care. This preview release introduces the core event logging workflow so users can create events, add entries, and review a timeline of what happened and when.

## What's new
- Create and manage events
- Log entries with timestamps
- View recent activity in a dashboard
- Secure sign-up and sign-in flows
- Per-device session handling
- API support for event and entry operations
- Local observability and preview deployment support

## Preview status
This is a beta/preview release. Some sharing and coordination features are intentionally limited or staged for the next release cycle.

## Important notes
- Session handling is device-aware
- Auth is rate-limited for protection
- This release is intended for preview feedback and iteration

## Coming next
- Full shared event workflows
- Recipient access and coordination
- Notifications and reminders
- Expanded mobile support
